# Portfolio fonts

The portfolio uses self-hosted Latin subsets of Public Sans (variable, weights 400–600) and IBM Plex Mono (400). Both are distributed under the SIL Open Font License; licenses are included alongside the fonts.

Sources: Google Fonts `ofl/publicsans` and `ofl/ibmplexmono`, downloaded September 2026. The CSS family aliases are Reaptor Sans and Reaptor Mono (files: `sans-latin.woff2`, `mono-latin.woff2`). Public Sans was selected after comparing it with IBM Plex Sans and Archivo in the rendered portfolio.
